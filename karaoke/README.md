# Mídia do Karaokê

- Coloque vídeos prontos de karaokê em `karaoke/videos/`.
- Coloque instrumentais em `karaoke/audio/`.
- Vídeos podem ter a letra já incorporada à imagem.
- Para áudio instrumental, cadastre a letra sincronizada por frase em `karaoke.js`, com `inicio` e `fim` em segundos.
- Depois de adicionar ou remover mídia, atualize o array `catalogoKaraoke` em `karaoke.js`.
- O site GitHub Pages é estático: o navegador não consegue gravar uploads diretamente no repositório. Adicione os arquivos pelo VS Code e faça commit/push normalmente.
- Use apenas vídeos, instrumentais e letras que você tenha autorização para publicar.
